# wallpapers-test.crosspoint-plugin

Temporary standalone CrossPoint plugin repository used to validate Plugin Hub capability filtering.

The installable payload is in `wallpapers-test.crosspoint-plugin/` and follows Plugin Hub's normal automatic-discovery layout.

This repository is intentionally temporary and should remain a Community plugin. The payload requires `catalog.images` and `catalog.cache` from firmware in the `crosspoint` family.
